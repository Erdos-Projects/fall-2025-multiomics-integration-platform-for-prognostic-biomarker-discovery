# Multi-Omics Integration Platform for Prognostic Biomarker Discovery

This repository provides a reproducible workflow for multi-omics data integration to identify prognostic biomarkers in glioblastoma. It includes a Colab notebook with all analyses, a Python script version for reproducibility, and an HTML report summarizing the findings.

---

## Background and Motivation

Glioblastoma is one of the most aggressive brain tumors, with highly variable patient outcomes that are difficult to predict using single-omics data alone.
Integrating transcriptomic and proteomic profiles offers a systems-level view of tumor biology, helping reveal coordinated molecular programs associated with prognosis and treatment response.
This project implements a modular, transparent pipeline for such integration, enabling reproducible discovery of candidate biomarkers and pathways.

## Quick Start

1. **Set up your environment**

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r environment/requirements.txt
   ```

2. **Run the pipeline**

   ```bash
   python src/omics_integration_pipeline.py
   ```

3. **View the results**

   Open the generated report:

   ```
   reports/OmicsIntegration_Report.html
   ```

## Reproducibility

* The Colab notebook is mirrored as a Python script for version control and continuous integration.
* All dependencies are listed in `environment/requirements.txt`. You may also provide a `conda` environment file for broader compatibility.
* Figures and outputs are automatically saved to `reports/figures/` during execution.
